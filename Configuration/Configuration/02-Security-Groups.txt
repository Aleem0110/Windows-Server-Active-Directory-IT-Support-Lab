ACCESS MANAGEMENT MODEL
=======================

User
  |
  +-- Security Group
          |
          +-- Department Resource


IT ACCESS EXAMPLE
=================

IT Test User
     |
     +-- GG-IT-Users
             |
             +-- IT Department Resources


WHY GROUP-BASED ACCESS?
=======================

Permissions are associated with security groups rather than
being individually assigned to every user.

This provides:

- Easier administration
- Consistent access control
- Better scalability
- Simpler onboarding and offboarding
- Support for least-privilege access


SCALABILITY EXAMPLE
===================

500 Users
    |
    +-- Department Security Groups
              |
              +-- Department Resources

When a user changes departments, group membership can be
updated without redesigning the underlying resource permissions.
