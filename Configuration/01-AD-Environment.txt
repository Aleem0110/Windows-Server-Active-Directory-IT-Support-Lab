IT

Active Directory Model
----------------------
User
  |
  +-- Department OU
          |
          +-- Security Group
                    |
                    +-- Authorized Resource

Administration Model
--------------------
Identity management is centralized through Active Directory.

Departmental organization is handled using Organizational Units.

Resource authorization is handled using security groups.

Security Principle
------------------
Least-privilege access is used as the underlying access-control principle.

Lab Scope
---------
This configuration represents the Windows Server infrastructure
actually implemented and verified during the lab.
