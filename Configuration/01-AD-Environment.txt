WINDOWS SERVER ACTIVE DIRECTORY LAB

IT

ACTIVE DIRECTORY MODEL
----------------------
User
  |
  +-- Department OU
          |
          +-- Security Group
                    |

ADMINISTRATION MODEL
--------------------
Identity management is centralized through Active Directory.

Departmental organization is handled using Organizational Units.

Resource authorization is handled using security groups.


SECURITY PRINCIPLE
------------------
Least-privilege access is used as the underlying
access-control principle.


LAB SCOPE
---------
This configuration represents the Windows Server
infrastructure actually implemented and verified
during the lab.
